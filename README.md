# Curtis Otiende — Personal Profile

A responsive static personal profile website designed for GitHub Pages.

## Deploy to GitHub Pages

### Option 1 — Repository root
1. Create a GitHub repository, for example `curtisotiende.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

### Option 2 — Existing repository
Upload the three website files to the branch/folder configured for GitHub Pages.

## Before publishing
Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your actual profile URLs.

The site uses Google Fonts via CSS. It will still function if the fonts cannot be loaded.
